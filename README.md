# Apoorva Portfolio — React + Vite

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Replace profile photo

In `src/components/Hero.jsx`, replace the `.portrait-placeholder` with:

```jsx
<img src="/profile.jpg" alt="Apoorva" className="profile-photo" />
```

Then put your photo at `public/profile.jpg`.

## Resume

The resume is already copied to `public/Apoorva-Resume.pdf`.
